# Portafolio — Ángel David Avirama

Portafolio personal desarrollado con Next.js, React, TypeScript y Tailwind CSS.

## Requisitos
- Node.js 20.9 o superior
- npm

## Ejecutar localmente

```bash
npm install
npm run dev
```

Abre http://localhost:3000.

## Compilar para producción

```bash
npm run build
npm run start
```

## Personalización

- Datos personales, proyectos, tecnologías y enlaces: `app/page.tsx`.
- Colores: selector flotante en la página; temas definidos en `app/page.tsx` y variables CSS en `app/globals.css`.
- Metadatos y título del navegador: `app/layout.tsx`.

## Antes de publicar

1. Confirma que los enlaces de cada proyecto sean los repositorios correctos y públicos.
2. Si tienes capturas reales de tus proyectos, podemos reemplazar las visualizaciones ilustrativas de las tarjetas.
3. Verifica que las descripciones reflejen exactamente tu contribución.
4. Publica en Vercel importando el repositorio de GitHub.
